# Learn Java in 21 Days ☕

A structured 21-day Java learning journey designed to help beginners build a strong foundation in Java programming through daily topics, examples, and hands-on practice.

## 📚 About This Repository

This repository contains a day-by-day roadmap for learning Java in 21 days. Each day focuses on a specific concept, gradually progressing from Java basics to object-oriented programming, collections, exception handling, and more.

Whether you're a beginner starting your programming journey or someone looking to refresh Java fundamentals, this repository provides a clear and practical learning path.

---

## 🎯 Learning Goals

By the end of these 21 days, you will be able to:

* Understand Java syntax and program structure
* Work with variables, data types, and operators
* Use conditional statements and loops
* Create and use methods
* Apply Object-Oriented Programming (OOP) principles
* Handle exceptions effectively
* Work with collections and data structures
* Understand file handling basics
* Build small Java applications independently

## 🛠️ Prerequisites

Before starting:

* Install Java JDK (Java 17 or later recommended)
* Install an IDE:

  * IntelliJ IDEA
  * Eclipse
  * VS Code with Java Extensions
* Basic understanding of how to use the command line

---

## 🚀 Running Java Programs

Compile a Java file:

```bash
javac FileName.java
```

Run the compiled program:

```bash
java FileName
```

Example:

```bash
javac HelloWorld.java
java HelloWorld
```
